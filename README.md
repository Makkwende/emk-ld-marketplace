# EMK L&D Workflow — Marketplace

This repo is a Claude plugin marketplace containing the **emk-ld-workflow** plugin,
built by Dr. Maurine Kwende / EMK Learning Solutions.

## For students: how to install and test the plugin

1. Open Claude (claude.ai) in your browser.
2. Open the **Customize** menu in the left sidebar.
3. Go to the **Plugins** tab.
4. In the **Personal plugins** section, click the **+** button, then choose **Add marketplace**.
5. Choose **Add from a repository**, and paste this repo's GitHub URL.
6. Once it syncs, browse the marketplace, find **emk-ld-workflow**, and click **Install**.
7. Start a new chat and try a prompt like: "Help me build a project workflow for a new
   manager onboarding program" — Claude will use the plugin's skill automatically.

## For Dr. Kwende: how to update the plugin later

Edit `plugins/emk-ld-workflow/skills/emk-ld-workflow/SKILL.md` in this repo and push the
change (or just re-upload the file on GitHub's website). Students who installed the
plugin from this marketplace get the update automatically next time they use it.
